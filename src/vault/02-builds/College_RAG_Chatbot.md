# College RAG Chatbot

> [!ACHIEVEMENT]
> GitHub: [DeepShah1406/College_RAG_Chatbot](https://github.com/DeepShah1406/College_RAG_Chatbot)

## Overview
An intelligent student enquiry system built for educational institutions. It uses RAG to answer complex questions about admissions, course details, and campus policies.

## Key Technical Features
- **OCR Integration**: Uses **Tesseract OCR** to extract text from scanned brochures and legacy PDFs.
- **Hybrid Retrieval**: Combines standard vector search with negative prompting and guardrails to keep queries on-topic.
- **Service Routing**: Context-aware suggestions for campus services (Financial Aid, Counseling, etc.).

## Tech Stack
- **AI**: LangChain, ChromaDB, Groq.
- **Extraction**: PyPDF2, Tesseract.
- **Backend**: FastAPI & Streamlit.
