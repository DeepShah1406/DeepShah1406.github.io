# Machine Learning on Autism Dataset

> [!ACHIEVEMENT]
> GitHub: [DeepShah1406/autism-ml-case-study](https://github.com/DeepShah1406/autism-ml-case-study)

## Project Objective
Early detection of Autism Spectrum Disorder (ASD) through automated machine learning models. The study focuses on analyzing behavioral traits and demographic data to identify patterns indicative of ASD.

## Technical Implementation
- **Data Engineering**: Handled imbalanced datasets using `Imbalanced-learn` and performed comprehensive feature engineering.
- **Model Comparison**: Evaluated multiple models including **Logistic Regression**, **SVM**, and **XGBoost**.
- **Results**: 
  - Training Accuracy: **86.72%**
  - Validation Accuracy: **81.82%**

## Impact
- Created a baseline for early intervention tools.
- Demonstrated the efficacy of XGBoost in detecting complex behavioral patterns.
